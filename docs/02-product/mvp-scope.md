# Границы MVP: что вошло и почему

## 1. Главный выбор

Мы не воспроизводим весь кредитный процесс банка. Мы берём один сквозной путь — от задачи клиента до денег на счёте или до понятного плана — и делаем его прозрачным с обеих сторон. Исследование показало, что самые сильные боли лежат **до и после** заявки, а не в самой форме ([discovery](../01-research/discovery.md), раздел 1). Поэтому в MVP глубоко проработаны предоценка, объяснение результата и маршрут, а форма заявки — минимальная.

## 2. Этапы

| Этап | Что входит | Почему |
|---|---|---|
| Вход | Демо-учётки без регистрации; одна учётка — одна компания с ИНН | Ограничение организаторов: регистрация не нужна |
| Клиент, 6 шагов | Цель (фраза или форма, сумма, срок) → Компания (подтвердить по ИНН) → Финансы (выручка, личные платежи, просрочки; можно пропустить) → Предложение (предоценка и 1–3 варианта) → Документы (только недостающее) → Отправка (сводка, 2 согласия) | Минимум ввода: всё, что банк знает сам, подтягивается из счёта и реестров |
| Банк, Б1–Б4 | Б1 полнота и сверка выручки со счётом → Б2 обогащение: БКИ и уровень ЗСК → Б3 баллы по 9 факторам и стоп-факторы → Б4 решение по правилам продукта; триггеры специалиста | Кейс требует этапов обработки и модели решения; разделение скоринга и решения — тезис кейса, стр. 14 |
| Исходы | Одобрено, иные условия, нужны данные, отказ + отдельно приостановка по 115-ФЗ | Кейс: «итог не обязательно бинарен» |
| После решения | Принять условия → подписать (демо) → выдача (демо); отклонить иные условия; отозвать до решения; истечение 30 / 14 дней | Кейс допускает моделировать подписание и выдачу |
| Маршрут | Шаги, срок, пересчёт без новой заявки и без БКИ; «Готов к подаче» по порогу | Центральная ценность продукта (Г2) |
| Специалист | Очередь исключений, досье, решение только с кодом причины, журнал | Кейс: часть операций требует сотрудника; принцип — максимум решений без человека |

## 3. Роли

| Роль | В MVP | Почему |
|---|---|---|
| Предприниматель: владелец = директор = поручитель (ИП, микро-ООО) | Да | В публичных источниках звучат почти только владельцы; у ИП одна личная кредитная история — отсюда слои «бизнес» и «владелец» |
| Кредитный специалист | Да | Нужен для исключений и для демонстрации «скоринг ≠ решение» |
| Администратор демо | Да | Состояние сервисов, все заявки, статистика, сброс демо |
| Финансовый директор, бухгалтер, уполномоченный сотрудник (персона P6) | Описаны, не реализованы | Требуют прав и делегирования (готовит / подтверждает) и МЧД; подтверждающих данных о них почти нет — один голос брокера ([discovery](../01-research/discovery.md), раздел 3) |

## 4. Данные

Все данные синтетические, внешние системы — локальные моки (`ml/fixtures/personas.json`).

| Источник | Что берём | Когда |
|---|---|---|
| Счёт в Альфе | Обороты за 6 мес., срок обслуживания, кредиты бизнеса | С предоценки |
| ЕГРЮЛ / ЕГРИП | Статус, форма, ОКВЭД, возраст бизнеса | С предоценки |
| ФНС «Прозрачный бизнес», ФССП, арбитраж | Налоговый долг, блокировки, исполнительные производства, иски, банкротство | С предоценки |
| Ответы клиента | Выручка, личные платежи, были ли просрочки за 2 года | Предоценка (со слов, помечено) |
| БКИ | Кредитная история и нагрузка владельца | **Только после подачи и согласия** |
| Уровень риска ЗСК (115-ФЗ) | Зелёный / жёлтый / красный | **Только после подачи** |
| Выписка другого банка | Обороты, не видные банку | По запросу «Нужны данные» |

## 5. Проверки

Стоп-факторы, сверка заявленной выручки с оборотом по счёту (порог 30%), 9 факторов скоринга, лимит по формуле продукта, 115-ФЗ, триггеры специалиста, проверка текста языковой модели на выдуманные числа и обещания. Значения — [`business-rules.md`](../03-requirements/business-rules.md), BR-03…BR-11.

## 6. Продукты

Только оборотный кредит и овердрафт. Главная заявленная цель МСБ — оборотный капитал и закупки ([discovery](../01-research/discovery.md), раздел 2); два продукта с разными формулами лимита и стоимости достаточно, чтобы показать «одинаковые баллы — разные условия».

## 7. Что вне MVP и почему

| Что | Почему не делаем сейчас |
|---|---|
| Новый клиент без счёта в Альфе | Предоценка и решение опираются на обороты, которые банк видит сам |
| Роли внутри компании, МЧД | См. раздел 3 |
| Залоги; полноценное поручительство | Нужны оценка имущества и отдельный процесс; поручительство учтено упрощённо: у ООО владелец — поручитель, потолок 5 млн ₽ |
| Кредитная линия, лизинг, факторинг, рефинансирование | Не нужны, чтобы доказать механику; добавляются конфигурацией |
| Реальные ЭЦП, выдача денег, интеграции с ЕГРЮЛ, БКИ, ФНС, ЗСК | Запрещено условиями (автономность) |
| ML-модель скоринга | Объяснимость важнее точности; кейс допускает правила и балльную модель |
| Уведомления вне кабинета, мобильное приложение | Запрещено условиями |
| Распознавание документов | Выписка P5 «распознаётся» из синтетики — смысл интеграции сохранён |
