# Деплой на сервер (Yandex Cloud)

Стенд для жюри: один сервер, весь проект в Docker. Наружу открыт только сайт (Caddy, порты 80/443, HTTPS сам),
backend, ml, llm и postgres работают во внутренней сети Docker и снаружи недоступны.

## 1. Создать сервер в Yandex Cloud

Консоль → Compute Cloud → «Создать ВМ»:

| Параметр | Значение |
|---|---|
| Образ | Ubuntu 24.04 LTS (подойдёт и 22.04) |
| vCPU / RAM | **без LLM:** 2 vCPU, 4 ГБ · **с LLM:** 4 vCPU, 8 ГБ |
| Гарантированная доля vCPU | 100% (с долей 20–50% сборка и ответы будут медленными) |
| Диск | SSD 30 ГБ |
| Публичный адрес | Автоматически (лучше сделать статическим, чтобы ссылка не менялась) |
| Логин | например, `deploy` |
| SSH-ключ | содержимое `~/.ssh/id_ed25519.pub` |

Если у сети есть группа безопасности — разрешить входящие TCP 22, 80, 443.

## 2. Задеплоить

С компьютера, где лежит проект:

```bash
scripts/deploy.sh deploy@<IP>              # без LLM
scripts/deploy.sh deploy@<IP> --with-llm   # с локальной LLM (8 ГБ ОЗУ)
```

Скрипт:
1. копирует проект на сервер (`rsync`, без `node_modules`, `.venv`, `.env`);
2. при первом запуске ставит Docker из репозитория Ubuntu;
3. при первом запуске создаёт на сервере `.env` со случайными `SECRET_KEY`, паролем базы и служебным токеном;
4. собирает и запускает контейнеры, ждёт здоровый backend.

Адрес стенда: `https://<IP через дефисы>.sslip.io` — бесплатный домен, указывающий на IP сервера;
Caddy сам получает для него HTTPS-сертификат. Свой домен — поменять `SITE_ADDRESS` и `CORS_ORIGINS` в `~/smart-credit/.env`
на сервере и перезапустить скрипт.

## 3. Обновить стенд

Тот же скрипт ещё раз: код копируется заново, `.env` и данные базы сохраняются.

## 4. Проверить

```bash
npx newman run docs/postman/smart-credit.postman_collection.json --working-dir . \
  --env-var "baseUrl=https://<адрес стенда>/api/v1"
```

Коллекция в конце сбрасывает демо-данные. Папка «0. Сервисы» обращается к ml и backend напрямую
(`localhost:8001`, `localhost:8000`) — на сервере эти порты закрыты, эти два запроса падать будут ожидаемо.

## Полезное на сервере

```bash
cd ~/smart-credit
docker compose -f docker-compose.yml -f docker-compose.prod.yml ps        # состояние
docker compose -f docker-compose.yml -f docker-compose.prod.yml logs -f backend
```

Сброс демо-данных перед показом — в кабинете администратора (`admin` / `demo`).
