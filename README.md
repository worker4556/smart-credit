# Smart Credit

Умный кредитный кабинет предпринимателя — прототип цифрового кредитного конвейера для малого и микробизнеса (Альфа-Хак 2026).

Предприниматель описывает задачу, а не выбирает продукт; система по ИНН собирает данные, ведёт заявку как трекер и объясняет любое решение. Банк видит ту же заявку проверенной и вручную разбирает только пограничные случаи.

## Сервисы

| Папка | Стек | Порт |
|---|---|---|
| `frontend/` | React + Vite + TypeScript | 3000 |
| `backend/` | FastAPI + PostgreSQL | 8000 |
| `ml/` | FastAPI, scikit-learn | 8001 |
| `mocks/` | FastAPI | 8002 |

Инструкция по запуску появится вместе с каркасом (`docker compose up`).

## Как работаем

1. `git pull --rebase` перед началом работы и перед каждым пушем.
2. Каждый работает в своей папке; общие файлы (`docker-compose.yml`, `docs/`) меняем, предупредив команду.
3. Изменения API — сначала в `docs/api-contract.md`, потом в коде.
