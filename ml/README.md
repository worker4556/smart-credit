# ml — скоринг, предоценка, подбор продукта, объяснения

Stateless FastAPI-сервис на порту **8001**. Вызывается только backend. Контракт — [docs/api-contract.md, раздел C](../docs/api-contract.md#c-ml--внутренний-api-httpml8001).

## Структура

```
service/      рантайм (идёт в Docker-образ)
  features.py   входная схема, производные признаки, биннинг — общий код для обучения и сервиса
  scorecard.py  применение карты из artifacts/scorecard.json, PD, грейд, факторы
  catalog.py    подбор продукта под задачу клиента (правила)
  explain.py    шаблонные объяснения + опциональный LLM через Ollama
  main.py       эндпоинты
training/     офлайн (в образ не входит)
  generate_data.py   синтетический датасет МСБ (data/synthetic_sme.csv, в Git не хранится)
  train_scorecard.py обучение → artifacts/scorecard.json + artifacts/report.json
artifacts/    обученная скоринговая карта (читаемый JSON) и отчёт о качестве
tests/        pytest
```

## Модель

Классическая банковская **скоринговая карта**: биннинг признаков → логистическая регрессия → баллы
(600 баллов при шансах 20:1, +40 баллов удваивают шансы). Объяснимость: каждый фактор даёт видимый вклад в баллы.

| Признак | Источник |
|---|---|
| Возраст бизнеса | ЕГРЮЛ |
| Долговая нагрузка = (текущие платежи + новый аннуитет) / месячная выручка | БКИ + заявка |
| Сумма к годовой выручке | заявка |
| Макс. просрочка за 12 мес | БКИ |
| Число активных кредитов | БКИ |
| Налоговая задолженность, массовый адрес | ФНС |
| Подтверждение выручки выпиской | документы |
| Форма бизнеса, отраслевой риск по ОКВЭД | ЕГРЮЛ |

Качество на тесте (синтетика, 40 000 компаний): **Gini 0.59, KS 0.47**. Грейды: A < 2% PD, B < 5%, C < 10%, D < 20%, E — выше.
Подробно — `artifacts/report.json`.

## Команды

```bash
uv sync                                    # окружение (Python 3.12, версии из uv.lock)
uv run uvicorn service.main:app --reload --port 8001
uv run pytest                              # тесты
uv run python -m training.generate_data    # синтетика → data/
uv run python -m training.train_scorecard  # обучение → artifacts/
```

Swagger: http://localhost:8001/docs

## LLM (опционально)

По умолчанию выключен — объяснения шаблонные. Чтобы включить, задайте `OLLAMA_URL=http://ollama:11434`
и `OLLAMA_MODEL=qwen2.5:3b` (open-weights). Любая ошибка или таймаут LLM (`LLM_TIMEOUT_SECONDS`, 5 с) → шаблонный текст.
